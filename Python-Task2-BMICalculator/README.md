# Advanced BMI Calculator

## Project Overview
The Advanced BMI Calculator is a Python application that calculates Body Mass Index (BMI) using a user's weight and height. It provides a graphical user interface and classifies BMI results into different categories.

## Features
* User-friendly graphical interface using Tkinter.
* Calculates BMI based on weight and height.
* Displays BMI categories with colour-coded results.
* Validates user inputs and displays error messages.
* Stores BMI records in an SQLite database.
* Displays BMI history in a table.
* Generates BMI trend graphs using Matplotlib.
* Supports calculations for multiple users.

## Technologies Used
* Python
* Tkinter
* SQLite
* Matplotlib

## Formula
BMI = Weight (kg) / Height (m)²

## BMI Categories
* Underweight: BMI below 18.5
* Normal weight: BMI from 18.5 to below 25
* Overweight: BMI from 25 to below 30
* Obese: BMI of 30 or above

## How to Run
1. Install Python 3.
2. Install Matplotlib using `python -m pip install matplotlib`.
3. Run `bmi_calculator.py`.
4. Enter the user's name, weight in kilograms, and height in metres.
5. Click Calculate BMI to view the result.
