# Advanced Weather App

## Project Overview
The Advanced Weather App is a Python application that displays real-time weather information for a selected city. It provides a graphical user interface with a light sky-blue background and displays current weather conditions along with hourly and five-day forecasts.

## Features
* User-friendly graphical interface using Tkinter.
* Searches weather information using a city name or ZIP code.
* Displays current temperature in Celsius and Fahrenheit.
* Shows feels-like temperature and weather conditions.
* Displays humidity, wind speed, and atmospheric pressure.
* Shows sunrise and sunset times.
* Displays the next 6 hours of weather forecasts.
* Provides a 5-day weather forecast with weather icons and temperature details.
* Supports switching between Celsius and Fahrenheit.
* Detects the approximate location using IP-based location detection.
* Displays error messages for missing API keys, invalid locations, and connection problems.
* Supports scrolling to view content that extends beyond the visible window.

## Technologies Used
* Python
* Tkinter
* Requests
* Pillow (PIL)
* OpenWeatherMap API
* IPinfo API

## How to Run
1. Install Python 3.
2. Install the required libraries using `python -m pip install requests pillow`.
3. Obtain an API key from [OpenWeatherMap](https://openweathermap.org/).
4. Set the API key in Windows Command Prompt using `set OPENWEATHER_API_KEY=YOUR_API_KEY`.
5. Run `weather_app.py`.
6. Enter a city name or ZIP code and click Search to view the weather information.
